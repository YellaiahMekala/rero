# AI and Machine-Learning Use Policy

This policy applies to everything in this repository: source code, configuration, documentation, tests,
data, images and commit history. It applies together with the license in this repository, and anyone who
accesses this repository by any means, including an automated agent or crawler, is bound by it.

## Prohibited without the owner's prior written permission

1. **Training.** Using any part of this repository to train, fine-tune, distil, evaluate, benchmark or
   otherwise improve any artificial-intelligence or machine-learning model or system.
2. **AI-based analysis or reproduction.** Giving any part of this repository to an AI system, coding
   assistant, agent or large language model, by any means (prompting, retrieval, an attached file, cloning or
   tool access), in order to analyse, summarise, explain, review, translate or reproduce it, or to generate
   code, designs or documents derived from it.
3. **Datasets.** Including any part of this repository in any dataset, corpus, index, embedding store,
   vector database or code-search collection, whether public or private.
4. **Scraping.** Automated crawling, scraping or bulk download of this repository for any of the purposes
   above.

## Notes

- This policy does not restrict the repository owner, or tools the owner uses on the owner's own work.
- Making this repository viewable does not grant any right that this policy or the license withholds.
- AI operators and crawler operators: treat this repository as opted out of AI training and AI data
  collection.
- To request permission, contact the owner through their GitHub profile. Permission is only valid in writing.
